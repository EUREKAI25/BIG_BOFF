------------------------------------------------------------
COPY STRATEGY PER BLOCK TYPE
------------------------------------------------------------

navbar_block:
- logo_text: brand name, short. Never a slogan.
- nav links: 3-4 max. Action-oriented or section names (not "Home"). Map to #id anchors.

hero_block:
- title: lead with the core value proposition or transformation. Max 10 words. No questions.
- subtitle: expand the promise with one concrete benefit or qualifier. Max 20 words.
- badge: optional trust signal or urgency trigger (e.g. "Nouveau", "Bêta gratuite", "Résultats en 48h").
- cta_primary_label: action verb + benefit or object (e.g. "Obtenir mon audit", "Démarrer gratuitement"). Max 5 words.
- cta_secondary_label: softer alternative action (e.g. "Voir comment ça marche"). Nullable if not needed.

stat_block:
- value: a specific, credible number or percentage. Never vague (e.g. "87%", "3 IA", "48h").
- label: what the number measures. Max 6 words. Benefit-framed if possible.
- Infer from proof elements in the brief. If no data available, use plausible specifics consistent with the brief.

steps_block:
- title: "Comment ça marche" or equivalent. Direct, no cleverness.
- subtitle: one line stating the outcome of following the steps. Optional.
- Each step title: imperative verb + object (e.g. "Analysez votre visibilité"). Max 5 words.
- Each step description: one concrete sentence explaining what happens. Max 20 words.

faq_block:
- title: "Questions fréquentes" or "FAQ". Keep it simple.
- questions: address real objections and concerns inferred from the brief and target user profile.
  Typical objections: price justification, time commitment, how it works, what's included, guarantees.
- answers: direct, complete, no fluff. Max 3 sentences each.

pricing_block:
- title: straightforward (e.g. "Nos offres", "Tarifs clairs").
- subtitle: one qualifying line (e.g. "Sans engagement, sans surprise").
- Each card name: short tier label (e.g. "Essentiel", "Pro", "Sur mesure").
- price: exact value from brief (e.g. "97€", "500€ / 6 mois"). Use {price} placeholder if variable.
- features: 3-5 bullet points max per card. Benefit-led, not feature-led. Specific > generic.
- cta_label: differentiate per card ("Commencer", "Choisir Pro", "Nous contacter").
- is_featured: true for the recommended/most profitable tier only.

cta_block:
- title: restate the core promise or create urgency. Max 10 words.
- subtitle: reduce friction or add reassurance (e.g. "Sans carte bancaire. Résultats sous 48h.").
- btn_label: same logic as hero cta_primary. Specific action.

testimonial_block:
- title: "Ce qu'ils en disent" or similar. Keep neutral.
- Each item content: specific result or transformation stated in first person. Max 3 sentences.
  If no real testimonials in brief: write plausible, specific, non-generic placeholders marked [À REMPLACER].
- name and role: realistic, profession-consistent with target user.

content_block:
- heading: optional. Introduces the sub-topic. Max 6 words.
- text: factual, benefit-oriented paragraph. No padding. Max 4 sentences.

footer_block:
- copyright: "© {year} BrandName. Tous droits réservés." Use current year.
- columns: group links logically (Produit, Légal, Contact, etc.).
- footer links: standard pages only (CGV, Mentions légales, Contact, Politique de confidentialité).

COPY QUALITY RULES
------------------------------------------------------------

- Specific beats generic: "87% des établissements absents de ChatGPT" > "beaucoup d'entreprises".
- Benefits beat features: "Sachez où vous en êtes en 48h" > "Rapport d'analyse fourni".
- No exclamation marks unless the tone explicitly requires it.
- No rhetorical questions in titles.
- Avoid: "révolutionnaire", "unique", "innovant", "solution complète", "de qualité".
- Consistency: the same entity (brand, product, user) must be referred to the same way throughout.
- Placeholder variables {city}, {price}, {project_name} may be used where the brief implies dynamic content.
