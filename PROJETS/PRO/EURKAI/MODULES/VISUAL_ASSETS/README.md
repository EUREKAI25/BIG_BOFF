# VISUAL_ASSETS — Générateur d'assets visuels EURKAI

Module pour la génération d'images via DALL-E et Replicate, avec harmonisation des couleurs.

## Modules
- `src/module.py` — `VisualAssetsGenerator` : génération images IA
- `src/harmony.py` — `harmony_transfer` : transfert HSL pour cohérence visuelle

## Exemples
- `examples/generate_thalasso_dalle.py` — Génération via DALL-E
- `examples/generate_thalasso_replicate.py` — Génération via Replicate
